# crud-1-java

Este projeto tem como objetivo colocar em prática aprendizado de API Rest/CRUD básico em Java

Funcionalidades:
Cadastrar novo usuário (POST)
Listar todos os usuários (GET)
Buscar usuário por ID (GET)
Atualizar dados do usuário (PUT)
Deletar usuário (DELETE)

Ferramentas:
Java 21
MongoDB
Postman
